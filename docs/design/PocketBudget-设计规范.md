# PocketBudget 设计规范

字号、行高、间距与颜色的统一约定。后续改版按这份规范对照，不能另起一套尺寸。

## 原则

少档位，跟系统，对齐对齐。只用 22 / 18 / 17 / 15 / 13 五档字号，不再出 16、12。单行统一为 48。颜色走 iOS 语义色，正负结余用固定色。不做装饰性空方块或占位图标。

- 同一张卡内，标题、内容行、底部操作行高得一致。
- 左右边距统一 16：页边、卡片内边、分组列表行内都一样。
- 导航用 ›，不用装饰图标或空方块。

## 字号与字重

| 档位 | 字号 | 字重 | 用途 |
| --- | ---: | --- | --- |
| 英雄数字 | 22 | bold | 按月统计的累计结余 |
| 圆环中心 | 18 | bold | 首页「剩余」 |
| 正文 | 17 | regular | 导航、设置、表单标签与输入 |
| 强调正文 | 17 | semibold | 卡片标题、主按钮、统计月份标题 |
| 数据 | 15 | regular | 单行备注、次要数值 |
| 紧凑金额 | 15 | semibold | 本月明细金额 |
| 辅助 | 13 | regular | 日期、页脚说明、预算占用、统计明细 |

不再使用 16 与 12。辅助符 › 与正文同档，17、tertiaryLabel、右对齐。

## 行高

| 类型 | 行高 | 用于 |
| --- | ---: | --- |
| 单行 | 48 | 导航、设置、表单、预算列表、本月明细、键值详情 |
| 双行记录 | 56 | 消费明细、分期列表 |
| 统计双行 | 88 | 按月统计的月份行 |
| 主按钮 | 48 | 记一笔、确认记账 |
| 表单底栏 | 64 | 含按钮与上下留白 |

48 与首页导航、设置行一致；56 容下 17 + 13 两行；88 是按月统计加高后的既定尺寸，不再压缩。同一张卡里不要混用多种行高。

## 间距与圆角

| 规则 | 值 |
| --- | --- |
| 页边、卡片外边距 | 16 |
| 卡片与分组列表内边距 | 16 |
| 行内字段间距 | 10 |
| 首页顶部留白 | 8 |
| 卡片与紧随的主按钮 | 14 |
| 区块之间 | 24 |
| 页底留白 | 24 |
| 卡片圆角 | 14 |
| 按钮圆角 | 12 |
| 分割线 | 0.33，separator，透明度 0.55 |

## 颜色

| 用途 | 色 |
| --- | --- |
| 主文字 | label |
| 次要文字 | secondaryLabel |
| 辅助符、占位提示 | tertiaryLabel |
| 首页、统计页背景 | systemGroupedBackground |
| 设置类页背景 | insetGroupedBackground |
| 卡片背景 | systemBackground |
| 结余 / 剩余为正 | #2E7D32 |
| 结余 / 剩余为负，超支 | #D32F2F |
| 结余为零 | label |
| 链接与表单主按钮 | #007AFF |
| 首页「记一笔」 | #2C2C2E，白字 |

金额完整格式带 ¥ 与两位小数；紧凑行去掉货币符号，整数不写小数，消费金额前加减号。本月明细日期用 MM-DD；其余时间用 YYYY-MM-DD HH:mm；月份用 YYYY-MM。

## 组件配方

### 单行导航与设置

行高 48。左侧标题 17 regular、label；右侧 › 或次要值 17。左右内边 16。用于首页导航、设置、备注、记一笔表单。

### 单行数据（本月明细）

行高 48。一行从左到右：日期 13 secondaryLabel、金额 15 semibold、备注 15 regular；字段间距 10，左右 16。无备注时写「消费」。空状态一行「本月暂无消费」，13 secondaryLabel，无左侧方块。卡片标题「本月明细」与「更多」也是 48；标题 17 semibold，「更多」 17 regular、#007AFF。

### 双行记录

行高 56。上行主信息 17 label，下行时间或补充 13 secondaryLabel。左右 16，上下内边 8。用于消费明细与分期列表。

### 键值详情

行高 48。左 17 secondaryLabel，右 17 label，左右 16。用于分期详情。

### 统计双行

行高 88。上行月份 17 semibold，下行明细 13 secondaryLabel，可两行。左右 16，上下内边 18。页顶汇总卡高 96，累计结余 22 bold。

### 主按钮

高 48，圆角 12，17 semibold。首页「记一笔」用 #2C2C2E 白字；记一笔表单「确认记账」与链接用 #007AFF。底栏内按钮左右边距 16。

### 时间进度（首页顶卡）

放在「预算 · 占用」之下、结余行之上。轨道高 4、圆角 2，左右边距 16；浅色轨道 `#E5E5EA`，深色 `#3A3A3C`，填充 `#007AFF`。说明用 13、secondaryLabel、居中，距轨道 6。自然月写「已过 n% · 距下月还有 n 天」；起始日大于 1 时写「距发薪还有 n 天」。起始日当天分别写「本月开始」或「今天发薪」。

### 小组件

只做小尺寸。圆环展示当月剩余；中心文字 15 bold，可缩放以免裁切。

## 样例

同目录下的 `PocketBudget-design-sample.html` 是按本规范渲染的界面样例，打开后可切换浅色 / 深色。
