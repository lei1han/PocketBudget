# PocketBudget（JSBox）

PocketBudget — 本地个人月度预算：设当月预算、记消费、分期预扣、结余滚动；支持导出/导入 JSON。

## 安装

1. 把 `PocketBudget.box` 传到 iPhone / iPad（隔空投送、文件 App、微信文件等均可）。
2. 用 **JSBox** 打开该文件完成安装（也可把 `.box` 改名为 `.zip` 再导入，本质相同）。
3. 在 JSBox 脚本列表中点「PocketBudget」运行。

要求：JSBox SDK ≥ 2.0，iOS ≥ 14；**桌面小组件**需 JSBox ≥ 2.12。

### 桌面小组件（小尺寸）

1. iOS 主屏幕长按 → 左上角 **+** → 搜索 **JSBox** → 选择 **小** 尺寸。
2. 添加到桌面后 **编辑小组件** → 运行脚本选 **PocketBudget**。
3. 展示 **本月剩余**（= 当月预算 − 消费 − 分期预扣，与首页一致）及圆环进度；超支时圆环与金额警示色；点按打开 PocketBudget。

数据来自同一沙盒 `data/budget-v1.json`，记账保存后会请求刷新时间线（系统不保证立即更新）。

## 使用说明

### 首页
- **顶卡**：圆环突出**剩余**（与小组件同口径）；小字「预算 · 占用」；底行「本月结余 · 累计结余」点按进入**按月统计**
- **主操作**：全宽「记一笔」主按钮
- **本月明细**：标题、预览列表与底部「更多 ›」整合为同一圆角卡片；点按标题、明细或「更多 ›」进入完整消费明细（可切月、左滑删、右上角记一笔）
- **底部栏**：「分期」「预算」「设置」三等分按钮（设/改当月预算；常用备注、导出/导入、检查更新）
- **记一笔**：insetGrouped 分组表单（金额 → 备注区「选择常用备注」菜单行 + 输入 → 时间）；底部固定「确认记账」；常用备注在「设置」维护；时间默认当前，可改历史时间

### 按月统计
- 顶卡（高 96）展示**累计结余**；下列各月卡片行（高 88）上下两层展示月份与「预算 · 占用/支出 · 结余」
- 从首页顶卡底行进入

### 预算沿用
- 进入新月份若未设预算：自动沿用上月金额并写入本月
- 若历史上从未设过预算：按 ¥0 计算，并提示先设预算

### 消费
- 记一笔为一屏表单，预设备注可点选
- 可记历史时间；左滑删除
- 不做就地改金额/备注：不对就删了重记
- 删除后结余与累计立即重算

### 分期
- 新建：总额、期数、首期月、备注
- 均摊，尾差进末期；各期按月预扣占用对应月预算
- **提前结束**：取消「当前月之后」未发生期次；已发生月份保留
- **左滑删除**（或详情「删除分期」）：移除计划及全部期次预扣，历史月占用一并撤销，结余立即重算（≠ 提前结束）

### 结余（滚动即时口径）
- 本月结余 = 预算 −（消费 + 分期预扣）
- 累计结余 = 历史已结束月结余之和 + 当月预览
- 可以为负（透支历史结余）

### 导出 / 导入
- **导出 JSON**：系统分享面板（可存到文件/隔空投送）
- **从剪贴板导入** / **从文件导入**：覆盖本地全部数据（导入前有确认）

数据权威文件：扩展沙盒内 `data/budget-v1.json`（另有 `$cache` 镜像）。

## 验收自测（六条）

1. **设/改当月预算**  
   首页 →「预算」→ 输入金额 → 顶卡「预算 · 占用」更新。切到历史月消费页，无法改历史预算（预算只动当月）。

2. **新增消费，剩余即时变**  
   记一笔后，顶卡圆环「剩余」、占用与「本月结余 · 累计」行、本月明细预览立即变化。

3. **未花完形成结余并计入累计**  
   预算大于占用时，本月结余 > 0；按月统计中累计 = 历史月结余之和 + 当月预览。

4. **超支扣累计，可显示负值**  
   消费或分期使占用 > 预算，本月结余为负；累计可为负。

5. **新建分期预扣各月**  
   新建 3 期后，各对应月「分期预扣」增加；首页已占用含分期。

6. **结束分期，未来月不再占用**  
   分期详情 → 提前结束 → 当前月之后的期次显示「已取消」且不再计入占用；当月及以前保留。

附加：导出 JSON 后清空或改数据，再导入，数据应恢复。

## 发布新版本（GitHub Release）

供维护者与 App 内「检查更新」使用；仓库已公开，无需 Token。

1. 在 `config.json` 的 `info.version` 写入新版本号（如 `1.0.6`），与将要打的 Git 标签一致（可带或不带 `v` 前缀，建议 `v1.0.6`）。
2. 在仓库根目录打包安装包（与 CI/本地一致）：
   ```bash
   zip -r PocketBudget.box main.js config.json README.md assets scripts -x "*.git*"
   ```
3. 提交并推送源码到 `main`（或合并 PR）。
4. 在 GitHub：**Releases → Draft a new release** → 选择标签 `v1.0.6`（或新建标签）→ 填写说明 → **上传附件** `PocketBudget.box`（文件名须与 App 内查找的一致）。
5. 发布 Release 后，用户在 JSBox 中打开 PocketBudget → **设置 → 检查更新** → 若有新版本则下载并通过 `$addin.save` 覆盖安装，完成后可 `$addin.restart()` 重启。

注意：更新仅替换脚本安装包，不会上传或覆盖 `data/budget-v1.json` 等本地预算数据。

## 本版不做

分类/图表、多账户币种、预算数据云同步、自动导入、小组件/捷径。
