# PocketBudget（JSBox）

PocketBudget — 本地个人月度预算：设当月预算、记消费、分期预扣、结余滚动；支持导出/导入 JSON。

## 安装

1. 把 `PocketBudget.box` 传到 iPhone / iPad（隔空投送、文件 App、微信文件等均可）。
2. 用 **JSBox** 打开该文件完成安装（也可把 `.box` 改名为 `.zip` 再导入，本质相同）。
3. 在 JSBox 脚本列表中点「PocketBudget」运行。

要求：JSBox SDK ≥ 2.0，iOS ≥ 14。

## 使用说明

### 首页
- 展示：当月预算、已占用（消费 / 分期）、剩余、本月结余、累计结余；顶部有**预算占用进度条**（超支警示色并显示 >100%/超支金额；预算为 0 时显示 0% 或「未设预算」，不除零）
- **记一笔**：insetGrouped 分组表单（金额 → 备注区含常用备注在上+输入在下 → 时间 → 主色确认按钮）；常用备注来自「设置」，点选填入备注框；时间默认当前，可改历史时间
- **设预算**：仅可改**当月**；历史月预算锁定
- **消费明细 / 分期 / 结余一览 / 导出导入 / 设置**：进入对应功能；**设置**中可增删改常用备注（本地 `data/note-presets-v1.json`）

### 预算沿用
- 进入新月份若未设预算：自动沿用上月金额并写入本月
- 若历史上从未设过预算：按 ¥0 计算，并提示先设预算

### 消费
- 记一笔为一屏表单，预设备注可点选
- 可记历史时间；左滑删除
- 不做就地改金额/备注：不对就删了重记
- 删除后结余与累计立即重算

### 分期
- 新建：总额、期数、首期月、备注
- 均摊，尾差进末期；各期按月预扣占用对应月预算
- **提前结束**：取消「当前月之后」未发生期次；已发生月份保留

### 结余（滚动即时口径）
- 本月结余 = 预算 −（消费 + 分期预扣）
- 累计结余 = 历史已结束月结余之和 + 当月预览
- 可以为负（透支历史结余）

### 导出 / 导入
- **导出 JSON**：系统分享面板（可存到文件/隔空投送）
- **从剪贴板导入** / **从文件导入**：覆盖本地全部数据（导入前有确认）

数据权威文件：扩展沙盒内 `data/budget-v1.json`（另有 `$cache` 镜像）。

## 验收自测（六条）

1. **设/改当月预算**  
   首页 → 设预算 → 输入金额 → 总览「当月预算」更新。切到历史月消费页，无法改历史预算（设预算只动当月）。

2. **新增消费，剩余即时变**  
   记一笔后，首页「已占用·消费」「剩余」「本月结余」与顶部占用进度条立即变化。

3. **未花完形成结余并计入累计**  
   预算大于占用时，本月结余 > 0；结余一览中累计 = 历史月结余之和 + 当月预览。

4. **超支扣累计，可显示负值**  
   消费或分期使占用 > 预算，本月结余为负；累计可为负。

5. **新建分期预扣各月**  
   新建 3 期后，各对应月「分期预扣」增加；首页已占用含分期。

6. **结束分期，未来月不再占用**  
   分期详情 → 提前结束 → 当前月之后的期次显示「已取消」且不再计入占用；当月及以前保留。

附加：导出 JSON 后清空或改数据，再导入，数据应恢复。

## 本版不做

分类/图表、多账户币种、云同步、自动导入、小组件/捷径。
